# Action-pruning-in-Reward-Adaptation

This repository contains the code for the TMLR paper *Provably Efficient Reward Transfer in Reinforcement Learning with Discrete Markov Decision Processes*.

The main entrypoint is [`run_experiments.py`](run_experiments.py). It lets you run collection, aggregation, and plotting from one place and writes the final aggregated CSVs to `results/<experiment-slug>/`.

## Installation

Install the package in editable mode:

```bash
python -m pip install -e .
```

Or install the dependencies directly:

```bash
python -m pip install -r requirements.txt
```

## How To Run

List the available experiments:

```bash
python run_experiments.py list
```

Inspect one experiment:

```bash
python run_experiments.py show dollar-euro
```

Run a full pipeline:

```bash
python run_experiments.py run dollar-euro --stage all --start 0 --end 30
```

Stages:

- `collect`: run the experiment scripts
- `aggregate`: combine per-seed CSVs into final CSVs under `results/<slug>/`
- `plot`: generate the experiment plot
- `all`: run `collect`, `aggregate`, and `plot`

Examples:

```bash
python run_experiments.py run dollar-euro --stage all --start 0 --end 30
python run_experiments.py run racetrack --stage all --start 0 --end 30
python run_experiments.py run frozen-lake --stage all --start 0 --end 30
python run_experiments.py run autogenerated-linear --stage all --start 0 --end 30
python run_experiments.py run autogenerated-nonlinear --stage all --start 0 --end 30
python run_experiments.py run noisy-combination --stage all --start 0 --end 30
```

If seed-level outputs already exist, you can rerun only aggregation or plotting:

```bash
python run_experiments.py run dollar-euro --stage aggregate --start 0 --end 30
python run_experiments.py run dollar-euro --stage plot
```

The aggregated outputs use semantic names such as `mqm_*.csv`, `qm_*.csv`, `ql_*.csv`, `sfql_*.csv`, and `clipped_ql_*.csv`.
